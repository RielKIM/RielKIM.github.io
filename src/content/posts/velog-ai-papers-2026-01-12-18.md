## 1. Learning Latent Action World Models In The Wild (Meta AI)

![](/images/velog/ai-papers-2026-01-12-18/figure-01.jpg)

**배경 및 문제**:
기존 world model(세계 모델)은 에이전트가 환경과 상호작용하는 방식을 학습하는데, 대부분 명시적인 "액션 라벨"이 필요했습니다. 예를 들어 "왼쪽으로 이동", "점프" 같은 구체적인 행동 정보가 있어야 했죠. 이는 단순한 로봇 시뮬레이션이나 비디오 게임에서는 가능하지만, 유튜브 영상처럼 실제 세계의 다양한 비디오에서는 이런 라벨을 얻을 수 없습니다.

**핵심 접근법**:
- **잠재 액션(Latent Action) 학습**: 명시적 라벨 대신, 연속적이면서도 제약된 잠재 공간에서 액션을 표현합니다. 이는 기존의 벡터 양자화 방식보다 실제 비디오의 복잡성을 더 잘 포착합니다.
- **교차 비디오 전이**: 한 비디오에서 학습한 환경 변화(예: 사람이 방에 들어오는 것)를 다른 비디오에 적용할 수 있어, 학습된 액션이 의미 있고 일반화 가능함을 보여줍니다.
- **범용 인터페이스**: 다양한 비디오의 서로 다른 embodiment(신체 형태)에도 불구하고, 알려진 액션을 잠재 액션으로 매핑하는 컨트롤러를 학습시켜 범용적으로 사용할 수 있습니다.

**결과**: 액션 조건부 베이스라인과 동등한 계획 성능을 달성하며, 실제 학습 시 액션 라벨이 전혀 필요 없었습니다. 이는 실제 세계 데이터로 확장 가능한 중요한 진전입니다.

[논문](https://arxiv.org/abs/2601.05230)

## 2. Extending Context by Dropping Positional Embeddings (DroPE)

![](/images/velog/ai-papers-2026-01-12-18/figure-02.png)

**배경 및 문제**:
언어 모델이 사전학습 시 사용한 것보다 긴 텍스트를 처리하려면 "컨텍스트 윈도우 확장"이 필요합니다. 기존 RoPE(Rotary Position Embedding) 스케일링 방법은 perplexity(혼란도)는 유지하지만, 실제로는 유효 컨텍스트를 "자르는" 효과가 있어 긴 범위의 정보 검색 작업에서 실패합니다. 예를 들어 "건초더미에서 바늘 찾기(needle-in-haystack)" 같은 작업에서 문서 전체를 활용하지 못하는 것이죠.

**핵심 통찰**:
위치 임베딩은 **"학습 시 비계(scaffold)"** 역할을 합니다. 학습 중에는 유용하지만, 테스트 시 학습 길이를 초과하면 오히려 방해가 됩니다. RoPE는 학습 중 빠른 attention 분포 발달을 돕지만, 테스트 시 시퀀스가 학습 길이를 넘어가면 문제가 됩니다.

**방법론**:
1. RoPE 기반 모델을 학습하거나 가져옵니다
2. 사전학습 후 위치 임베딩을 **완전히 제거**합니다
3. 원래 사전학습 예산의 0.5-2%만 사용해 짧은 재보정을 수행합니다

**결과**: 
- 5B 토큰 미만의 재보정으로 95%+ 문맥 내 성능 회복
- needle-in-haystack 작업에서 RoPE 스케일링 방법을 크게 능가
- 최대 7B 파라미터, 수조 개의 토큰으로 학습된 모델에서 검증
- LongBench에서 SmolLM 점수 10배 향상, 학습 길이의 2배까지 제로샷 확장

[논문](https://pub.sakana.ai/DroPE/)

## 3. Self-Evolving Search Agents Without Training Data (Dr. Zero)

![](/images/velog/ai-papers-2026-01-12-18/figure-03.jpg)

**배경 및 문제**:
멀티턴 검색 에이전트(여러 단계를 거쳐 정보를 검색하는 시스템)를 개발하려면 일반적으로 인간이 라벨링한 대량의 학습 데이터가 필요합니다. 이는 비용이 많이 들고 시간이 오래 걸립니다.

**핵심 접근법**:
- **자기진화 루프**: Proposer(문제 제안자)가 다양한 질문을 생성하고, 같은 기본 모델에서 초기화된 Solver(해결자)가 이를 학습합니다. Solver가 향상되면 난이도가 자동으로 증가하는 자동 커리큘럼을 만듭니다.
- **Hop-Grouped Relative Policy Optimization (HRPO)**: 구조적으로 유사한 질문을 클러스터링하여 그룹 수준의 베이스라인을 구축합니다. 이는 인스턴스별 최적화에 비해 계산 오버헤드를 줄이면서도 성능 품질을 유지합니다.

**의미**:
시스템이 외부 학습 데이터 없이 스스로를 가르치며, 점점 더 어려운 문제를 자동으로 생성하고 해결합니다. 이는 AI 개발에서 고비용 라벨링 데이터 의존성을 줄이는 잠재력을 보여줍니다.

**결과**: 완전 지도학습 검색 에이전트와 동등하거나 우수한 성능을 보이며, 라벨링된 데이터 없이도 복잡한 멀티턴 추론 능력이 발현될 수 있음을 입증했습니다.

[논문](https://arxiv.org/abs/2601.07055)

## 4. Unified Long-Term and Short-Term Memory for LLM Agents (AgeMem)

![](/images/velog/ai-papers-2026-01-12-18/figure-04.png)

**배경 및 문제**:
인간의 뇌처럼 AI 에이전트도 단기 메모리(작업 중인 정보)와 장기 메모리(오래 저장된 지식)가 필요합니다. 기존 시스템은 이 둘을 별도로 처리하고 고정된 규칙(예: "항상 최근 N개 저장")을 사용해 유연성이 부족했습니다.

**핵심 혁신**:
- **통합 메모리 관리**: 장기/단기 메모리를 단일 학습 가능한 정책으로 통합하여 작업 요구사항에 따라 동적으로 적응합니다.
- **도구로서의 메모리**: 메모리 연산(저장, 검색, 업데이트, 요약, 삭제)을 호출 가능한 도구로 노출합니다. 에이전트가 미리 정의된 규칙이 아닌 상호작용을 통해 최적의 메모리 전략을 학습합니다.
- **점진적 강화학습**: 메모리 연산으로 인한 희소하고 불연속적인 보상을 처리하는 3단계 학습 방식과 특수한 "step-wise GRPO" 알고리즘을 사용합니다.

**결과**: 5개 장기 벤치마크에서 작업 성능, 메모리 품질, 컨텍스트 효율성을 동시에 향상시키며, 여러 LLM 아키텍처에서 작동하는 아키텍처 독립적 접근법입니다.

[논문](https://arxiv.org/abs/2601.01885)

## 5. Active Context Compression for LLM Agents (Focus)

![](/images/velog/ai-papers-2026-01-12-18/figure-05.jpg)

**배경 및 문제**:
LLM 에이전트가 긴 작업을 수행하면 상호작용 히스토리가 계속 쌓입니다. 이로 인해:
- 계산 비용이 기하급수적으로 증가
- 처리 지연 악화
- 과거의 무관한 실수들로 인한 추론 품질 저하

**생물학적 영감**:
점균류(Physarum polycephalum)의 탐색 패턴에서 영감을 받았습니다. 이 생물은 자원과 경로를 효율적으로 관리하며, 불필요한 경로는 제거하고 중요한 발견은 강화합니다.

**핵심 접근법**:
- **자율적 메모리 관리**: 외부 요약이 아닌, 에이전트가 스스로 중요한 발견을 저장할 시점을 선택하고 원시 상호작용 기록을 제거합니다.
- **지식 블록**: 학습한 내용을 영구적인 "Knowledge" 블록으로 통합하고, 상세한 실행 히스토리는 제거합니다.
- **프로덕션 수준 도구**: 영구 bash와 문자열 대체 편집기를 포함한 실전 표준에 맞춘 도구킷 사용

**결과**: 
- SWE-bench Lite에서 Claude Haiku 4.5 테스트 시 토큰 소비 22.7% 감소 (14.9M → 11.5M)
- 정확도는 동일하게 60% 유지
- 특정 인스턴스에서 최대 57% 감소
- 평균 과제당 6.0회의 자율 통합 수행

[논문](https://arxiv.org/abs/2601.07190)

## 6. Agent-as-a-Judge (종합 서베이)

![](/images/velog/ai-papers-2026-01-12-18/figure-06.png)

**배경 및 문제**:
AI 시스템을 평가하는 일이 점점 복잡해지고 전문화되면서, 전통적인 단일 패스 LLM 판정자("LLM-as-a-Judge")가 불충분해졌습니다. 복잡한 작업은 단순히 한 번의 추론으로는 제대로 평가할 수 없습니다.

**주요 내용**:
- **LLM-as-a-Judge의 한계 식별**: 전통적인 LLM 판정자의 결정적 제약사항과 이를 에이전틱 접근법이 어떻게 극복하는지 분석합니다.
- **발전 분류체계**: LLM 기반 평가에서 에이전틱 평가로의 패러다임 전환을 체계화한 최초의 분류체계를 구축합니다.
- **에이전틱 능력**: 계획(planning), 도구 증강 검증(tool-augmented verification), 다중 에이전트 협업(multi-agent collaboration), 지속 메모리(persistent memory)를 통해 더 견고하고 검증 가능하며 미묘한 평가가 가능합니다.

**의미**:
평가 자체가 정적인 판단에서 동적이고 다단계 검증이 가능한 에이전트 기반 시스템으로 진화하고 있습니다. 특히 복잡한 작업에 대한 평가에서 중요한 변화입니다.

**기여**: 현재 방법론을 조사할 뿐 아니라, 최전선 과제를 분석하고 연구 방향을 제안하여 차세대 평가 시스템 개발을 위한 명확한 로드맵을 제공합니다.

[논문](https://arxiv.org/abs/2601.05111)

## 7. Efficient Lifelong Memory for LLM Agents (SimpleMem)

![](/images/velog/ai-papers-2026-01-12-18/figure-07.jpg)

**배경 및 문제**:
LLM 에이전트가 포괄적인 장기 메모리를 유지하면서도 추론 시 토큰 오버헤드를 최소화하는 것은 근본적인 긴장 관계입니다. 모든 것을 기억하면 비용이 너무 높고, 너무 많이 잊으면 성능이 저하됩니다.

**핵심 접근법**:

**1단계 - 의미론적 구조화 압축**:
비구조화된 상호작용을 필터링하여 컴팩트한 다중 뷰 인덱스 메모리 단위로 변환합니다. 필수 정보는 보존하면서 저장 요구사항을 극적으로 줄입니다.

**2단계 - 재귀적 메모리 통합**:
비동기 프로세스가 관련 메모리 단위를 더 높은 수준의 표현으로 통합하여 중복을 줄입니다. 이는 인간이 휴식 중에 경험을 통합하는 방식과 유사합니다.

**3단계 - 적응형 쿼리 인식 검색**:
쿼리 복잡도에 따라 검색 범위를 동적으로 조정합니다. 고정 크기 청크가 아닌 가장 관련성 높은 메모리만 가져와 효율적으로 컨텍스트를 구성합니다.

**결과**:
- 베이스라인 대비 F1 점수 26.4% 향상
- 추론 시 토큰 소비 최대 30배 감소
- 응답 품질을 희생하지 않으면서 포괄적 메모리 제공
- 장기 에이전트 작업을 실용적이고 비용 효율적으로 만듦

[논문](https://arxiv.org/abs/2601.02553)

## 8. Ministral 3 (Mistral AI)

**배경 및 문제**:
모바일 기기, 엣지 디바이스, 계산 및 메모리가 제한된 환경에서 실행할 수 있는 컴팩트하면서도 강력한 언어 모델이 필요합니다.

**방법론**:
**Cascade Distillation**: 반복적 가지치기(pruning)와 지속 학습(continued training)을 통해 더 큰 모델에서 작은 모델로 지식을 증류합니다.

**모델 라인업**:
- 3B, 8B, 14B 파라미터 버전
- 각 크기마다 3가지 변형: 사전학습, 인스트럭션 파인튜닝, 추론 변형
- 통합 이미지 이해 기능
- Apache 2.0 라이선스로 오픈소스

**의미**: 강력한 AI를 데이터센터가 아닌 사용자의 기기에서 직접 실행할 수 있게 하여, 프라이버시 향상과 지연 시간 감소를 가능하게 합니다.

[논문](https://arxiv.org/abs/2601.08584)

## 9. UniversalRAG

**배경 및 문제**:
실제 지식 베이스는 텍스트, 이미지, 비디오 등 여러 데이터 타입이 혼재되어 있습니다. 기존 멀티모달 RAG(Retrieval-Augmented Generation)는 다양한 모달리티를 단일 임베딩 공간에 억지로 넣으려 하는데, 이렇게 하면 임베딩이 의미가 아닌 모달리티별로 클러스터링되어 검색 품질이 떨어집니다.

**핵심 접근법**:
**모달리티 인식 라우팅**: 단일 임베딩 공간 대신, 각 쿼리에 대해 적절한 코퍼스(데이터 집합)와 세분성(granularity)을 동적으로 선택합니다. 텍스트 쿼리에는 텍스트 검색기를, 이미지 관련 쿼리에는 이미지 검색기를 사용하는 식입니다.

**이종 소스 처리**:
- 여러 데이터 타입을 각각의 강점을 살려 처리
- 다양한 세분성 수준(문단, 섹션, 전체 문서 등) 지원
- 쿼리 의도에 따라 최적의 검색 전략 선택

**결과**: 10개 벤치마크에서 단일모달 RAG와 통합 멀티모달 RAG 베이스라인을 모두 능가하는 성능을 보였습니다.

[논문](https://universalrag.github.io/)

## 10. MemRL

**배경 및 문제**:
LLM 에이전트가 새로운 경험에서 학습하려면 일반적으로 비용이 많이 드는 재학습이 필요합니다. 배포된 에이전트가 지속적으로 개선되려면 재학습 없이도 학습할 방법이 필요합니다.

**핵심 아이디어**:
고정된 언어 모델의 추론 능력과 진화하는 메모리 시스템을 분리합니다. 모델 자체는 변경하지 않고 메모리만 개선합니다.

**Two-Phase Retrieval 메커니즘**:

**1단계 - 의미론적 필터링**:
후보 메모리를 의미론적 관련성으로 필터링합니다. 쿼리와 의미적으로 유사한 과거 경험들을 찾습니다.

**2단계 - Q-value 기반 랭킹**:
필터링된 후보들을 학습된 Q-value(강화학습의 가치 함수)로 순위를 매깁니다. Q-value는 시행착오를 통해 계속 개선됩니다.

**학습 메커니즘**:
에이전트가 작업을 수행하면서 어떤 메모리가 유용했는지 경험하고, 이를 통해 Q-value가 업데이트됩니다. 마치 "이 메모리가 실제로 도움이 되었구나"를 학습하는 것입니다.

**결과**: 
HLE, BigCodeBench, ALFWorld, Lifelong Agent Bench 등 여러 벤치마크에서 기존 방법들을 능가하며, 모델 재학습 없이 지속적 개선이 가능함을 입증했습니다.
